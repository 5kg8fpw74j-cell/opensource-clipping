# Goals

Turn long streamer recordings and VODs we have permission to use into downloadable vertical MP4 highlights for TikTok, YouTube Shorts and Instagram Reels. The owner should be able to operate the system through a simple interface. Keep publication manual.

**First milestone** — Produce five distinct playable clips from one authorised video. Check each for 9:16 framing, understandable context, a strong moment, accurate animated subtitles, audio sync and sensible face tracking. Download all five before closing the GPU session.

**Later** — Improve automatic selection of funny, exciting and interesting moments against the owner's feedback. Once a single video works reliably, support several videos and batch processing with minimal manual setup.
